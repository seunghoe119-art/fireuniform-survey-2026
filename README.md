# 의용소방대 피복 구매 가능 품목 조회

2026년 상반기 조사표 기준으로 대원별 피복 구매 가능 금액과 품목을 보여주는 조회 전용 웹사이트입니다.

## 화면 동작

- 이름으로 대원을 조회하고, 동명이인은 소속을 선택합니다.
- 기존 대원은 9만원 한도 기준 남은 금액과 구매 가능한 품목을 확인합니다.
- 조사 합산 금액이 9만원 이상이면 `26년 상반기 피복수요조사 합산 시 9만원 초과` 안내를 표시합니다.
- 신규 대원은 조사표에서 `필요`로 표시된 품목 목록을 확인합니다.
- 입력, 신청 제출, 계정, 저장 기능은 제공하지 않습니다.

## 개발 실행

필요 조건: Node.js 22.13 이상 및 pnpm.

```bash
pnpm install
pnpm dev
```

프로덕션용 빌드:

```bash
pnpm build
```

## 데이터

조회 데이터는 `app/data/members.json`과 `app/data/products.json`에 있습니다. 이 저장소와 배포 사이트에는 조사표에서 추출한 대원별 구매 관련 정보가 포함됩니다. 입력 원본 Excel은 저장소에 포함하지 않습니다.
