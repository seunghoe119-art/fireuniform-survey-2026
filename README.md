# 의용소방대 피복 구매 가능 품목 조회

2026년 상반기 피복 조사표 기준으로 대원 이름별 구매 가능 금액과 품목을 조회하는 웹앱입니다.

- 이름만으로 대원을 조회합니다.
- 기존 대원은 9만원 한도 기준 잔액과 구매 가능한 품목을 확인합니다.
- 한도 초과자는 "26년 상반기 피복수요조사 합산 시 9만원 초과" 안내를 확인합니다.
- 신규 대원은 조사표에서 "필요"로 표시된 품목을 확인합니다.
- 신청, 사이즈 입력, 저장 기능은 없습니다.
- 소속대대 정보는 저장하거나 화면에 표시하지 않습니다.

## 실행

Node.js 22 이상:

```sh
npm install
npm run dev
```

이 공개 저장소에는 대원 이름과 구매 관련 조회 데이터가 포함됩니다. 원본 Excel과 Sites 내부 미리보기 런타임은 포함되지 않습니다.
